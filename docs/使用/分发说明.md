## 从源码运行与验证

需要Node.js 22.18+（22.x）或24+，首次安装需访问npm registry：

```sh
cd app
npm ci
npm test
npm run test:independent
npm run build
npm run start
```

浏览器打开 http://127.0.0.1:4173/。日常开发用npm run dev；Windows启动脚本启动开发服务器。应用数据保存在浏览器IndexedDB，源码安装不导入个人数据。不同浏览器来源、端口或设备不会自动同步。

当时 GitHub Actions 在 push 和 Pull Request 执行干净安装、Node 全量/独立反例和生产构建，权限限于读取源码。浏览器 93 项为原 G3 分离验收结果；重建后的作者回归另有 110 项。v0.2 的 CI 没有自动安装浏览器或重跑矩阵；v0.3 已配置完整浏览器门禁，远端运行需待本轮获准提交后核对，见[浏览器回归说明](../../app/tests/browser/README.md)与[Actions 记录](https://github.com/ANNLE5923/cardgrid-workbench/actions)。
