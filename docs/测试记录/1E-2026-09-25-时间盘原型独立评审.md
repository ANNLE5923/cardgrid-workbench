## 三、键盘与可达性评审（补测完成）

### 完整 Tab 焦点走查

实际按 Tab 键遍历全部可聚焦元素，共 26 个（原型特有元素 18 个，产品相关元素 8 个）。

**原型特有元素（实际产品不存在）**：S01—S07 场景按钮（7 个）、夜间主题/减少动态效果/交换内外圈复选框（3 个）、时间模拟 datetime 输入（6 个）、应用模拟时间/模拟外部修订/下次提交失败按钮（3 个）。

**产品相关元素（8 个）**：
1. 前一天（日期导航）
2. 场景日期（日期导航）
3. 后一天（日期导航）
4. 回到现在 09:30
5. −5 分钟
6. +5 分钟
7. 展开手牌
8. （表盘上的已安排片段按钮——出现在安排后）

**发现 F-KB-3（中）**：表盘弧段（SVG `path.dial-segment`）不在 Tab 焦点顺序中。这些元素有 `cursor:pointer` 且鼠标单击可选中并显示详情，但没有 `tabindex`，键盘用户无法用 Tab 选中某段查看详情或解锁调整。键盘用户只能用 ±5 分钟按钮移动指针，无法直接选择特定占用段。建议给表盘可交互段添加 `tabindex="0"` 和键盘事件（Enter/Space 激活），或确认时间列表中的片段按钮为键盘替代路径（已验证可聚焦）。

**发现 F-KB-4（低）**：操作确认后焦点回到 BODY。安排确认后，预览面板关闭，焦点未移到逻辑位置（如刚安排的片段或 DETAIL 面板），而是回到 document.body。键盘用户需要重新 Tab 导航。建议确认后将焦点移到 DETAIL 面板或新安排的片段按钮。

## 八、正面评价

1. **阅读顺序清晰**：自上而下、由主到辅，表盘是视觉中心，辅助信息环绕布局。
2. **状态反馈及时**：提示条上下文变化、预览区明确显示时间段和确认按钮、手牌数量实时更新。
3. **表盘段交互完整**：单击选中→绿色高亮→DETAIL 显示详情→固定段解锁按钮。鼠标路径通畅。
4. **跨午夜处理正确**：同源分片、次日"开始于"标注、不重复计数，符合 1C 合同。
5. **重叠确认明确**：列出重叠对象和区间，要求二次确认，不静默覆盖。
6. **多路径操作**：表盘拖拽 + 24H 预览条点击 + 时间列表 + 键盘微调，用户可选择最适合的方式。
7. **响应式覆盖完整**：5 个 CSS 断点 + reduced-motion + 夜间主题，覆盖目标尺寸和可访问性需求。
8. **查看与提交分离**：点牌只查看不写数据，上推/安排按钮才进入预览，确认按钮才提交。三层分离避免误操作。
9. **减少动态效果可靠**：手动开关和系统媒体查询双路径，实际计算样式验证所有动效消除。
