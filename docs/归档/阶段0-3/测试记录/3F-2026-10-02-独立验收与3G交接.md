## 2. 按影响分级的发现

### 3F-F01 / P1：拖拽重叠确认传错 Host 凭据

- 位置：src/components/time-dial/use-placement-session.ts:219；Host 对照 src/action-commands.ts:185—186。
- 复现：固定甲 09:15—09:45；手牌拖到 09:00，勾选重叠并确认。
- 实测 B06：提示“请明确确认本次完整重叠”，计划仍为 0。
- 根因：提交 acknowledgedOverlap=previewId；Host 要当前 candidate.acknowledgementId。两者是不同能力 ID。
- 修复：使用当前候选的 acknowledgementId；许可绑定 previewId + candidateId，移动、切偏移、新预览和 revision 变化全部清除。当前 HandFan 的独立 ack 布尔值也不能跨候选沿用。B07 显示只泛称冲突，须同时显示 blockers 全部标题、重叠区间及 reason。

### 3F-F02 / P1：旧来源占用被除以 5，跨整日旧占用消失

- 位置：src/components/time-dial/projection-adapter.ts:145—147。
- 反例 N01：09:02—09:09 正确绝对分钟为 542—549；实际变为 108.4—109.8（约 01:48），长度从 7 分钟变成 1.4 分钟。
- 反例 N02：区间从前一天持续到后一天、完整覆盖查看日，两端日期都不等于查看日时被直接丢弃。
- 后果：表盘可用空隙与正式占用不一致，命中 G3 拒绝条件。
- 修复：调用已有 splitRangeForDay/segmentsFor，保持分钟精度及 DST/跨日切片，用完整 LegacyRef（sourceId + path）包装显示身份。不得取整或改变原数据。

### 3F-F03 / P1：24:00 预览到了原日 00:00，按钮也无法到 24:00

- 位置：src/components/hand/HandFan.tsx:70—84；src/components/day-board.tsx:190。
- 实测 B11：23:55 点击 +5 仍为 23:55；父组件把 1440 限制到 1435。
- 实测 B12：从 23:55 在外环日界落牌，候选为 2026-09-28T00:00—00:30，应为 2026-09-29T00:00—00:30。
- 根因：geometry.landing 返回了 next-date，但 HandFan 只取 minuteOfDay，继续传旧 date。作者所述“按钮路径正确处理”未成立。
- 修复：落实 D023，保留 originView；取得次日 scene 后显示“原日24:00→次日00:00（未保存）”；取消恢复来源视图，保存留在真正日期。按钮和手势共用同一 intent，禁止给 Host 传 1440。

### 3F-F04 / P1：旧预览可留在新日期或新 revision 场景，且有两个提交会话

- 位置：src/components/day-board.tsx:74—97、120、131—132、180；use-placement-session.ts 的生命周期。
- B15：预览后切日期，旧“调整落点并确认”仍保留（count=1）。
- B16：盘面预览后点击“打出”，旧排期弹层和盘面调整同时存在。
- B17：另一窗口修改同 epoch revision 后，旧调整仍留在屏幕（count=1）；Host 已撤销能力，但 UI 仍显示可确认选项。
- N08：scene 不保存权威 token，只保留静态 version='3A-dial-1'，无法核对当前 scene/preview。
- 修复：DayBoard 管一个会话；切 date/zone、打开其他写弹层、external/replacement 时取消/失效旧候选与确认。保留用户输入，重新预览后才能提交；同窗口保存按既有订阅来源规则同步。scene 必须带 token 和来源版本，按同一权威快照关联元数据。

### 3F-F05 / P1：核心手势未接到正式表盘

- 位置：src/components/time-dial/TimeDial.tsx:192—200、232—245、258—273。
- B08：按住表盘转动后读数仍为 09:00，svg 没有旋转 pointer/wheel 接线。
- B09：拖候选滑块后落点不变，candidate path 只有 aria-hidden，没有交互。
- B10：双击已排计划只开只读概述，没有改期会话。
- 静态核实：计划双击改期/外拉撤回、固定双击明确解锁、预览径向换半日均未挂接表盘。现有列表按钮成功不能替代“所有手势已实现”的声明。
- 修复：按 3A 手势表串行接入同一 controller，加入 pointerId/capture 与最终落点处理。释放只预览；固定须明确解锁；事实/原计划轮廓/模板/旧来源/empty 全部保守只读。不要复制领域写路径。

### 3F-F06 / P1：新手牌子按钮的 Enter/Space 被父元素截走

### 3F-F08 / P2：DST 轴和叠色把不存在/不同偏移钟点误当正常占用
