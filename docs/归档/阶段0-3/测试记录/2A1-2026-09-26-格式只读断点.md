## 校验边界与待补项目

- `semanticValidationPending: true` 是刻意的门禁：当前返回的业务内容保持 `unknown`，不能作为 `DataV2` 的完整有效证明，也不能直接作为恢复、提交或迁移的输入。
- 当前检查格式版本、顶层字段有无、集合形状、ID 重复和部分核心引用；2A.4 仍须补齐**全部字段级类型/取值、旧集合内部结构、LegacyRef 源路径及目标类型、来源指纹和绑定唯一性、跨集合身份/状态不变量、时间/时区语义、容量与完整备份可恢复性**。校验函数不能补默认值或重写原文。
- `readWorkspaceSnapshot` 只接收已经打开的 `IDBDatabase`。旧 `src/store.ts` 的 `openDatabase` 在升级事件中会写入，不能用它建立这条只读路径；2A.5 切换正式入口前须替换该打开/读取流程并逐项审查旧写入口。
- 合成测试只证明纯模块与模拟的 readonly 请求；尚无新格式真实 IndexedDB 并发、恢复、清空、外部浏览器或真实数据验收。
