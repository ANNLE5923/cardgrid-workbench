## 配置与 Planner 断链清单（静态核对，浏览器未复现）

1. 配置工坊的 saveConfig 仅保存 Data.config。启动 reload 会调用 importDefinitions，但 planner.legacyImported 为真时立即返回。首次导入后新增或修改 config.cards / config.schedules，不会自动同步 planner.rules / planner.templates。
2. Inbox“转为 Card”调用 resolveCapture(..., '')，得到无日期 Task；Today 只读取 task.date===date。领域有改期命令，现有 Inbox 页面没有“排入今天”操作，捕获 → 转 Card → Today 的页面主路径中断。
3. 配置工坊编辑 config.schedules，Schedule 编辑并应用 planner.templates，两个相似的模板入口不共享实时数据。配置工坊“P2 再将它应用到日期”的文案与现有 Schedule 能应用日型的功能不一致。
4. Today 可以操作当天例行实例，Planner 有规则状态和星期字段；页面缺少完整的 Planner Rule 新增、暂停、归档入口。旧习惯卡仅首次导入为规则。
