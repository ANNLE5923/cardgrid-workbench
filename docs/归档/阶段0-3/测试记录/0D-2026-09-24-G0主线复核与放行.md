1. **可重复性缺陷，已修复。** 原 R2-02 在未设时区的机器上期待上海日期；用 `$env:TZ='UTC'; node --experimental-strip-types --test tests/r2-regression.test.ts` 实际复现失败：实际 2026-09-20、期待 2026-09-21。现有 Ubuntu CI 未指定时区。测试现在显式覆盖 Asia/Shanghai 与 UTC 并恢复环境变量，生产日期逻辑不变。

4. **资料口径修正，采纳。** 同源标签页共享 IndexedDB，新读取返回最新修订；旧的是页面持有的版本。预览的日程模板数是 Config.schedules，不是 Planner.templates。schema v1 迁移后启动会导入定义，最终 legacyImported=true。Top3 无乐观选择，失败后保持原已保存状态且候选可重试。
