| 项目 | 本轮处理 |
| --- | --- |
| R01 / R02 日界 | 按钮和手势将24:00转换为次日00:00；先取得次日readDay再切场景，显示“未保存”；候选仅叠在同日期、时区、token的场景。取消恢复originView，成功留在保存日期。 |
| R03 / R08 生命周期 | 日期/时区变化结束旧预览，跨窗口变化同步失效；读日按请求序号丢弃晚到结果。活动预览、输入弹层和手动操作跨午夜保持日期并提示，闲置今日继续自动切换。原G2实际草稿在同epoch外部revision变化时保留。 |
| R04 焦点 | 调整弹层复用useFlowFocus：进入、Tab约束、Escape取消、回到触发手牌；成功后触发项消失则回对应标题。盘面指针仍可操作。 |
| R05 旋转 | 记录起始focus、累计顺时针角差，使用geometry.rotate冻结公式；不再把命中墙钟分钟当旋转角差。 |
| R06 / R07 外拉 | 记录指针ID、起始对象和半径；有效松手时，计划走RetractPlan，预览只取消。pointercancel / lost capture不撤回、不保存；预览取消恢复原视图。 |
| A01 请求 | 一个排期控制器，预览请求串行执行，中间移动合并到最新落点；pending立即隐藏旧候选/确认许可并禁用提交。按钮弹层复用同一个控制器实现。 |
| A02 固定授权 | 使用用户显式解锁的首个能力；重预览先取新解锁再释放旧预览。晚到/失败的裸解锁定向绑定到有效原区间并取消，释放具体能力。表盘双击固定块先显示显式解锁入口。 |
| A03 重试 | same-command保留完整Command（ID、token、preview、candidate和ack）；变更落点/候选生成新提交。故障专项包含保存前失败、保存成功但丢响应、重放、重复提交。 |
| 来源身份 | 模板只读身份按真实FixedView引用关联判断；合法固定ID即使含template-projection前缀仍是固定。分组和叠色使用来源命名空间；legacy引用用JSON元组避免分隔符碰撞。 |
