## 运行与体验

在 CardGrid 根目录运行：

```powershell
node docs/归档/v0.3/原型/workshop-a0/server.mjs
```

打开 <http://127.0.0.1:4175/>。服务只监听本机；端口占用时先检查已有 A0 服务，或设置 `CARDGRID_A0_PORT`，不要覆盖原产品的 4173 端口。

| 链接 | 验证问题 |
| --- | --- |
| [工坊矩阵](http://127.0.0.1:4175/?view=workshop) | 牌堆主次、行动/书目区分、原卡编辑位置 |
| [抽卡模式](http://127.0.0.1:4175/?view=drawing) | 卡背快转、第一次前置、第二次翻开 |
| [Today 入口](http://127.0.0.1:4175/?view=today) | Today 保持产品默认视角，“去抽卡”作为就近入口 |
| [静止列表](http://127.0.0.1:4175/?view=drawing&display=list&still=1) | 无动画的等价两步选择与键盘路径 |
| [500 张压力样本](http://127.0.0.1:4175/?view=drawing&count=500&display=sphere) | 密集遮挡与切换列表的可用性，不代表批准容量 |

体验路径：

1. 工坊点击“阅读与学习”→“日常行动 / 我的书架”，观察层级返回；点击卡面查看或试改原卡。
2. 抽卡点击一张卡，确认它停转并前置；再次点击前置卡翻开。前置卡保留相同牌序与 ID。
3. 阅读行动的书名初始未选。“随机”是第一个可选择项，主动选择后立即填入具体书目；也可手选或进入可选书目球面。
4. 取消书目球面返回时保留原书名；使用一本书后回到同一行动。收回并重新查看同一行动也保留已填书名，不自行重抽。
5. 普通无槽行动可直接接受；两次有意接受增加两份独立内存手牌，展开后逐份展示来源日期。样稿分组只作位置示意，正式身份按 C0 实现。
6. “副本归档”放在手牌页，显示只读归档样例。

Tab / Shift+Tab 在当前弹层内移动，Enter 操作，Esc 逐层返回。输入时不拦截普通字符。关闭单卡回原卡，关闭球面回原牌堆；背景层使用 inert 并暂停运动。

## 小屏与容量观察

- ≤650px 默认列表，仍保留“选择前置→翻开”两步。主动切到球面时先静止，可以明确操作运动开关。
- 系统 `prefers-reduced-motion` 默认列表并停止运动；主动切球面仍保持静止。
- 720/390/320px 均检查主命令、详情与键盘路径；390/320px 另检查十张卡的静止球面命中区域完整可见。
- 500 张同时铺在球面上明显遮挡；建议大牌堆优先列表，球面是否分页或限定展示密度需在 P07 / A3 决定。本样稿没有把容量建议变成正式规则。
