## Overview

CardGrid 是本地优先的个人工作台：日程、卡片、Top3、Inbox、例行、复盘。工作方式是**打开就用，看完就走，键盘不脱手**。界面先回答用户在哪里、当前任务是什么、下一步可以做什么，再决定颜色、材质和动效。

视觉上保留浅米白纸色底、松绿主色和暖灰边栏。纸面感是品牌外观，不替代导航与信息结构。没有渐变、霓虹或营销式 hero；视觉权重给今天的时间盘、当前行动、Top3 和 Inbox。设计原则参考 [Fluent Design：Fluent](https://spicytater.cn/terms/fluent-design)：导航、间距、材质和控件行为要让任务自然进入下一步，Mica/Acrylic 并非必选材料。

**状态**：本文同时记录现有视觉基础与后续设计目标。时间盘、手牌及阻尼已有隔离原型；新焦点色、面板间距和最终交互尚未完整同步到生产页面，验收时须按1F阶段边界逐项核对。

### Fluent 在 CardGrid 中的落地顺序

1. **任务与上下文**：显示当前日期、当前视角、选中的卡牌或时间区间；主要命令和结果靠近操作对象。
2. **层级与节奏**：先用标题、分组、邻近关系和 4px 间距节奏组织内容，再决定是否需要边框或独立表面。列表和详情不必都装入相同的卡片。
3. **跨尺寸连续性**：桌面与窄屏保留同一套操作语义；空间不足时重排导航、命令和详情，保持当前上下文与主要动作可见。
4. **自然反馈**：选中、吸附、无效落点、滚动边界都有可辨识反馈；动效解释状态变化，并照顾减少动态效果的设置。

**Key Characteristics:**
- 桌面左侧边栏（220px）+ 右侧内容区；窄屏重排导航，始终标明当前视角
- 三级表面差承载层级：页面底 `#f7f8f4` → 卡片 `#fffefa` → 浅灰块 `#eef1e9`
- 1px 暖灰边 `#dfe4da`，不用投影分层级（对话框除外）
- 松绿 `#315e50` 是通用操作主色；时间盘和卡牌的语义色另有规则
- 按钮 8px 矩形，卡片 12px 圆角，胶囊只给标签/分段切换
- Inter 一套字体，时间数字用 tabular-nums
- 浅色为默认，深色 `.app.night` 是完整反色变量集

## Colors

### 浅色主题（默认）

| Token | Hex | 用途 |
|---|---|---|
| `--bg` | `#f7f8f4` | 页面底色，最冷的一层 |
| `--surface` | `#fffefa` | 卡片/面板底，纸面白 |
| `--soft` | `#eef1e9` | 浅灰块、hover、Top3 槽、candidate chip |
| `--line` | `#dfe4da` | 1px 边框和分隔线 |
| `--side` | `#f0f3eb` | 左侧边栏底色，比 bg 略暖 |
| `--ink` | `#2c4239` | 主文字，深松绿不是纯黑 |
| `--muted` | `#758279` | 次要文字、说明、面包屑 |
| `--accent` | `#315e50` | 主色：主按钮、选中 nav、Top3 数字圈、fixed 块左边条 |
| `--accent-hover` | `#3c715c` | 主按钮 hover |
| `--focus` | `#a07527` | 浅色主题的键盘焦点环；与三种浅色表面均有超过 3:1 的对比 |

### 语义色（稀缺）

| Token | Hex | 只给 |
|---|---|---|
| `success` | `#2f7d4f` | 完成状态、成功提示 |
| `warning` | `#b8742a` | 警告、Pending 但需注意 |
| `danger` | `#ab5142` | 危险操作（清空工作台）、错误 |

日终的红色“空时间”是时间盘专用语义，应使用独立 token，并同时配图例或文字；不要复用危险按钮的 `danger` 语义。卡牌颜色可延续到磁吸区间预览，但不能只靠颜色区分有效、选中与无效落点。具体色值待时间盘原型检验浅色和夜间主题后确定。

**Do**：主色松绿用于通用操作。状态色、卡牌颜色和时间盘颜色各有明确含义。
**Don't**：不要给普通按钮换第三个彩色；不要用松绿做大面积背景；不要为普通分类发明鲜艳色，分类色走 pastel 底 + 深字。

### 夜间主题

`.app.night` 覆盖全套变量：`--bg #19241f`、`--surface #23312b`、`--soft #2d4035`、`--line #405044`、`--ink #e2e9df`、`--muted #abb8ac`、`--accent #457b62`、`--side #1d2a22`、`--focus #c7a252`。组件结构沿用，颜色变量分别校验。

## Typography

- **字体**：`Inter, system-ui, 'Microsoft YaHei', sans-serif`。不需要定制字体。
- **h1** 30px / weight 620 / letter-spacing 1px。今天日期和页面大标题。
- **h2** 17px / weight 600。卡片标题。
- **body** 14px / line-height 1.75。正文和列表。
- **small/muted** 12px。说明文字。
- **caption** 11px / letter-spacing 2px。边栏分组标题、eyebrow。
- **数字**：时间、日期、倒计时一律 `font-variant-numeric: tabular-nums`，避免数字跳动。
- **字重**：标题 600–620，正文 400，按钮 500。不用 700。

### 分区标签规范

页面各功能分区标题统一使用**英文大写标签 + 中文副标题**格式，用 `/` 分隔。英文标签用 caption 样式（11px / letter-spacing 2px / muted 色），中文副标题用 body-small 样式。

| 分区 | 标签格式 |
|---|---|
| 时间盘 | `TODAY / TIME` 或 `TIME / 表盘` |
| 当前选择详情 | `DETAIL / 当前选择` |
| 时间线列表 | `TIMELINE / 同一投影` |
| 手牌 | `HAND / 待安排` |

英文标签是视觉锚点，中文副标题是实际说明。新增分区时遵循同一格式，不混用全中文或全英文。

## Layout

### 结构

```
.app (flex, min-height 100vh)
├── .sidebar (220px, sticky, 边栏)
└── main (flex:1, max-width 1500px, padding 0 42px)
    ├── header (83px, 面包屑 + 重新载入)
    ├── .heading (32px 顶距, eyebrow + h1 + 说明)
    └── 各页内容
```

### 边距

- 基距 4px。
- 面板内 padding 24px（`.panel`）；密集列表按内容选择更小间距。
- 卡片之间 20px margin。
- 按钮/输入框 10px 垂直、15px 水平。
- 边栏内 36px 上下、24px 左右。

### 网格

- Today 双栏（`.todaycolumns` 1fr 1fr，≤800px 折单栏）。
- Top3 三列等宽（≤800px 折单栏）。
- Inbox 左右双栏（1.2fr / 0.8fr，≤800px 折单栏）。
- 数据页双栏卡片（≤650px 折单栏）。

## Elevation

| 层级 | 处理 | 用途 |
|---|---|---|
| 0 | 表面差，无边框 | 页面底、导航 |
| 1 | `--surface` + 1px `--line` | 需要独立分组的面板 |
| 2 | `--soft` 底 | Top3 槽、chip、hover 行 |
| 3 | 轻微阴影 | dialog、message |
| 4 | `dialog::backdrop` `#142b2466` | 模态遮罩 |

常规页面优先用标题、邻近关系与分隔线建立层级；需要独立表面时再用面板。材质只表达表面关系，不能替代信息结构。常规卡片不加 box-shadow；对话框可用轻微阴影。

## Components

### Buttons

- **`.primary`**：松绿底白字。主操作。hover `#3c715c`。
- **默认 `button`**：`--surface` 底、1px `--line` 边。次级操作。
- **`.quiet`**：透明、无边、muted 字、12px。辅助/删除入口。
- **`.danger`**：红字 `#ab5142`、浅红边。只给"清空工作台"这类不可恢复操作。
- **`:disabled`**：`opacity .45`，`cursor: default`。

### Inputs

- 8px 圆角、1px `--line` 边、padding 10px。
- focus：3px `var(--focus)` outline，offset 3px；浅色主题 `#a07527`，夜间主题 `#c7a252`。
- checkbox 16px、`accent-color: var(--accent)`。

### Panels

`.panel` = `--surface` 底 + 1px 边 + 12px 圆角 + 24px padding + 20px 下边距。只在内容需要独立成组时使用；日程、列表、设置项和详情可以用连续表面或分隔线组织，避免每个区域都变成等权重卡片。

### 日程块（schedule-block）

- **fixed**（固定课程/不可改）：左 4px `--accent` 实色边 + `--soft` 底。
- **flexible**（弹性可拖）：左 4px 透明边 + 描边或更浅底。
- 一眼能分：fixed 是"砖"，flexible 是"草稿纸"。

### Routine 行

- 底部 1px `--line` 分隔，padding 10px 0。
- checkbox + 标题 + 右侧状态小标签。
- 完成后标题 `line-through` + muted。
- **不要**给 routine 行加花哨动画或状态色点。

### Top3

- 三列等宽，每格 58px 高、`--soft` 底、8px 圆角。
- 左侧 26px 圆形松绿数字圈。
- 空槽显示"选择今天要保护的任务"。
- Top3 是"今天最重要的三件"，不是积分排行榜。

### 快速捕获

- 输入框 flex:1 + 右侧主按钮"放入 Inbox"。
- 旁边 11px muted 提示"约 10 秒"。
- 捕获后底部显示最近 3 条 Inbox（chip 形式）。
- 这是 Raycast 式核心交互，输入框要有视觉重量，不要缩成小字段。

### Inbox 列表

- 左右双栏：左列表（1.2fr）右编辑面板（0.8fr）。
- 列表项：无边框、底部 1px 边、padding 15px 0。hover 变 `--soft`。
- 选中记录后右侧面板显示原文 + 标题输入 + 丢弃/归档/转 Card 三按钮。

### Dialog

- 16px 圆角、`--surface` 底、遮罩 `#142b2466`。
- 危险确认要用户输入"清空"二字才能提交。

## 时间盘与手牌交互（隔离原型已验证，正式页面待接入）

实施合同见[1F](./08-1F正式合同与阶段2边界.md)。阶段2先实现导航/主命令/选择与保存反馈、表单及时间列表、事实只读/批注、浅夜主题和可见焦点；阶段3接入最终双环/扇形/液态动效并统一主要页面。原型截图或桌面手势通过，不代表生产保存、真实触屏或小屏完整验收。

### 日终空时间

- 一天结束时，表盘上没有被固定日程或已打出 Card 占用的区间显示为红色“空时间”占位。红色覆盖实际空区间，并用图例或文字说明其含义。
- 空时间占位只描述时间盘的空缺，不自动生成完成事实。计划与实际记录仍按各自的确认规则处理。
- **1C 已决定（D017）**：按工作区所选时区的当地日结束自动显示，不需要日终按钮；补记或调整安排后立即重算。已关闭应用无需后台运行，下次查看已结束日期时直接派生；不持久化红色区间或结束标记。
- 确认后只以实际区间占时，原计划保留为对照轮廓；固定安排、未确认活动计划和实际区间取并集，红色为当天范围的补集。重叠不重复计时。

### 实际时间确认

- 实际起止精确到分钟，计划仅作预填；可调整后确认。按 D016 允许提前确认未来结束时间，确认页明确标出“结束时间尚未到达，确认后不可修改”。保留独立确认时间，不在结束时再次自动完成。
- 与其他安排/事实重叠时按 D015 展示对象和重叠区间，再次确认后记录；原事实立即锁定，后续只有追加说明。当前合同及原型接口见 [1C 文档](../归档/阶段0-3/产品设计/07-1C合同收敛与原型接口.md)。

### 手牌展开、查看与打出

- 手牌默认叠放在页面底部的固定位置；展开后卡片直接悬浮于内容上方，不出现贯穿屏幕底部的方框容器。卡片在屏幕下半部围绕同一个屏幕外支点，按角度向左右扇形展开；每张卡露出一部分可识别内容。窄屏可给出独立的文字操作路径。
- 点某张卡后，该卡转正、放大为独立的查看浮窗；其他卡片留在原处，页面不出现遮盖“当前选择”的整块底座。选中查看不等于打出。
- 从查看浮窗再次向上推，卡牌液态形变为固定指针所指绝对时间上的连续弧形滑块。松手后停在预览状态，不直接保存。按住滑块沿圆周移动只调整滑块落点，表盘保持不动；向内或向外移动可切换前后十二小时。按钮和键盘保留等价操作。
- 展开的每张卡是独立、不受手牌容器裁剪的悬浮组件。按住有轻微悬浮抖动，拖动时可自由移动；卡牌上边缘接触表盘刻度先在外圈生成虚拟滑块，继续向盘心推进、卡牌遮住外圈时切至内圈。绿色信息栏同步显示名称、起止时间和时长。松手时若虚拟滑块已出现，卡牌收缩形变并留下该滑块预览；只有在无虚拟滑块处松手才吸回手牌。松手本身不提交计划。
- 卡牌形成的预览滑块或已保存的计划滑块向外拖过表盘外缘并松手，可形变回手牌。预览滑块只取消未提交的落点；已保存计划须执行撤回并保留相应事件记录。内外圈切换不会触发回收。固定日程和完成事实不变成手牌。
- 指针固定朝向使用者，初次打开读数为当前时刻。按住表盘时，表盘、所有滑块及数字刻度整体旋转，指针不动；顺时针转向更早时间至 00:00，逆时针转向更晚时间至 24:00，不绕回。中心显示指针读数。两条十二小时环同时显示，内圈 00–12、外圈 12–24；5 分钟一顿的磁吸只用于操作，不把每单位画成独立细条。15 分钟卡形成一段连续的 3 单位滑块，25 分钟卡形成一段连续的 5 单位滑块。
- 数字刻度完整标出 1–12，随表盘旋转。拖盘或拖滑块不应触发浏览器文字选择。计划与固定滑块可双击快捷进入调整预览；再次双击该预览滑块取消调整，原安排保持锁定。完成事实只读。
- 表盘左侧设 24 格竖向预览条，每格一小时。左指针显示现在时刻，点击回到现在；右指针显示表盘固定指针的读数，能落在小时格内部。指针扫到的所有重叠项目共同轻微放大，在“当前选择”中逐项列出。
- 24 格预览条还显示固定日程、计划和完成事实的色段；点击色段展开只读批注窗口，列出该时刻所有相关项目的名称、类型、时间、时长和概述，不能从预览条编辑。
- 卡牌打出只在指针指向的一个绝对时间形成落点；夏令时重复当地刻度仍需明确偏移。卡牌安排允许与固定日程、活动计划或完成事实重叠；预览逐项列出交叉对象和区间，用户明确再次确认后才保存。已有事实保持原样和锁定，固定日程移动仍须先解锁。跨日重叠也按完整区间检查。
- 盘面以连续色段表示每项占用，交叉部分用独立叠色标记；红色仍只表示日终空时间。候选、选中和重叠需同时有线形或文字反馈，不能只靠颜色。重叠不抹去原项，也不能悄悄安排。
- 跨午夜源区间在当日最后片段标“续次日 →”，次日标“开始于 YYYY-MM-DD”，详情保留完整起止；仅跨中午或恰好00:00结束不标续次日。夏令时日用偏移说明和完整时间列表区分重复/缺失时刻，24格仅表达当地小时刻度。

### 页面滚动边缘

- 可滚动页面到达边缘后继续拉动时，给出位移逐渐减小的阻尼反馈；松开后回到边界，不让页面停在越界位置。
- 优先沿用设备和浏览器已有的自然滚动反馈。自定义效果不得与表盘拨动、卡牌拖动或系统手势争夺输入；减少动态效果设置下缩短或取消回弹动画。

## Do's and Don'ts

### Do

- 先用标题、邻近关系和命令位置建立层级，再按需使用 `--bg` / `--surface` / `--soft`。
- 主色松绿用于主按钮、通用选中态和 fixed 边条；键盘焦点使用独立的高对比 token。
- 按钮 8px 矩形，卡片 12px，胶囊只给标签。
- 时间数字用 tabular-nums。
- 空状态文案具体："还没有日程模板。可以先在配置工坊创建。" 不要写"空空如也"。
- 危险操作二次确认，且要打字确认。
- 保存失败时保留用户输入（R2-01 修复契约：onSave 返回 boolean，成功才清空）。
- 让当前日期、选中的卡牌或时间区间、可执行命令及其结果始终容易找到。

### Don't

- 不要渐变、不要霓虹、不要大气 hero 图。
- 不要给按钮换彩色（主操作永远松绿）。
- 不要 pill 按钮——胶囊只给标签和分段切换。
- 不要纯黑文字（用 `#2c4239` 深松绿）和纯白底（用 `#fffefa`）。
- 不要为每个状态发明新颜色。
- 普通内容卡不用 box-shadow；独立悬浮手牌/查看浮窗可用轻阴影表明当前浮起或拖动层次。
- 不要把所有列表、日程和详情都包装成相同的浮动卡片。
- 不要让营销文案风格进产品 UI。
- 不要自动把 Inbox 捕获塞进 Top3 或 Today。

## Responsive

| 断点 | 变化 |
|---|---|
| >1050px | 双栏 Today/Inbox，max-width 1500px |
| ≤1050px | main padding 收窄到 23px，边栏 185px |
| ≤800px | Today/Inbox 折单栏，Top3 折单栏，捕获输入竖排 |
| ≤650px | 边栏变顶部横向导航，日历双栏折单栏，卡片 padding 20px |

在 720px、390px 和 320px 宽度下逐项检查：导航能说明当前视角；标题、主要命令、列表/详情结果完整可读；时间盘的前后十二小时不混淆；展开手牌仍可选中每张卡，且不遮住磁吸目标。窄屏通过重排关系解决空间不足，不等比缩小整张桌面页面。

触摸目标：按钮 ≥40px，输入框 ≥40px；牌堆、露出的手牌和时间盘有效落点也应有可操作的命中区域。键盘与触摸完成同一任务。

## 给 AI Agent 的提示

- 改样式前先读这份文件，所有颜色走 CSS 变量，不要硬编码 hex。
- 加新组件时，先说明它服务哪个任务、与相邻内容和命令是什么关系，再决定表面（bg / surface / soft）与圆角。
- 主操作永远 `.primary`（松绿）。次级用默认 button。辅助用 `.quiet`。
- 新增彩色前先问自己：能不能用 `--soft` 底 + 深字替代。
- 夜间模式不要写新组件，只靠 `.app.night` 变量覆盖。
- 新时间盘或手牌交互按“查看 → 上推吸附为连续滑块 → 调整时间和半日 → 核对重叠 → 确认打出”的状态检查视觉与键盘反馈；不得把原型规则写成生产现有功能。
