## 目标与用户路径

默认 Today 直接提供正式双环时间盘、手牌、排期、实际确认与事实批注。
路径：打开 Today → 去抽卡 → 明确接受 → 返回 Today 安排 → 确认实际 → 查看事实。
解决当前默认 Today 为旧版只读页面、正式操作藏在“抽卡手牌 → 当日”的绕路问题。

## 范围与接口

- 复用 daily 的正式 DayBoard；“抽卡手牌 → 当日”成为 Today 的导航快捷入口，只有一处正式日常页面。
- 保留抽取、手牌管理和归档视图。成功接受后增加返回 Today 的按钮，用户仍可继续抽取或查看手牌。
- DayBoard 向 app 回传会话视图（日期、时区、落点、是否跟随当前时间）；返回时恢复手动浏览上下文。跟随当前时间的视图返回时取真实当前日和时间。
- 会话视图按 workspace epoch 隔离，不持久化、不增加数据字段；恢复、清空或迁移替换工作区后重新初始化。
- Today 保留显式准备日型和快速记录。Schedule 继续提供完整时间记录与旧版只读兼容查看；旧格式 Today 保留只读兼容入口。
- 继续使用正式 client、具名命令、预览与回执。事实只读、批注追加、来源日、五分钟计划网格与实际分钟精度均沿用现行合同。

本项不启动记录统计、第二领域、Inbox 转换、全面导航重构、数据升级或个人数据处理，不修改容量和备份规则。

## 完成标准

1. 空白与已有工作区默认 Today 显示正式时间盘与手牌；浏览与切日不创建计划、事实或例行安排。
2. 从 Today 抽卡并接受后，返回原浏览日期、显示时区与手动落点；接受仅创建独立手牌，排期仍须明确确认。
3. Today 可以完成排期、改期、撤回、实际确认和批注；刷新后读取同一权威记录。
4. 同 epoch 更新保留操作输入；保存失败与外部版本冲突仍走现有保护。工作区 epoch 替换清除旧视图和预览。
5. 保留跨午夜、DST、重叠确认、固定解锁、七日归档和旧数据只读回归；桌面与 320px 的按钮路径可用。
