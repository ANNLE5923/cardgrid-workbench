# 日记（一天一篇的自由书写）

确认日期：2026-10-05。本项基于已发布的 v0.4 Today 与仓库整理提交 `a8be1c4`，用户已确认日记版本为 v0.5.0 并授权提交、推送。用户已逐条确认本合同记录的形态决策；实现与修复状态见[v0.5 版本索引](../归档/v0.5/README.md)，本轮收尾未改变下述数据合同。

## 目标与用户路径

把现有"系统自动生成、人不能主动写"的归档记录，扩展为可以主动书写、一天一篇、随时续写修改、按天翻阅的日记。

路径：打开"日记" → 月历选日（默认今天）→ 直接写纯文本 → 停顿自动存、看到"已保存" → 用箭头在有文字的天之间翻，或在月历逐日点选 → 需要时补写过去某一天。

定位：日记是**个人自由文本，不是权威记录**；权威记录是系统归档日志与确认后的事实。因此日记不适用"事实只读、批注只追加"的锁定哲学，可随时改写。但日记仍保存在正式工作区内，走具名命令、进入完整备份。

## 数据与版本

- 新增 JournalEntry：`id`、`version`、`date`（本地日期 YYYY-MM-DD）、`zone`（IANA 时区）、`text`（纯文本）、`createdAt`、`updatedAt`；唯一键 `(date, zone)`。
- 数据版本升至 **Data v4**（dataFormat `action-v4`）：DataV4 在 DataV3 基础上增加 `journalEntries` 集合，其余集合不变；备份相应为 BackupV4。
- 升级走现行迁移：先完整备份 → 预览 v3→v4（仅追加空 `journalEntries`，不改任何现有数据）→ 用户显式提交。不自动升级。
- 旧 v0.3/v0.4 客户端遇到 `action-v4` 时明确提示"不支持的新版本"，不把数据误判为损坏。

## 范围与接口

书写与创建：
- 一天一篇、纯文本、实时续写修改。**懒创建**：打开某日未写任何有效文字不建档；首次有效文字才落库。
- 建档后允许把文字删空并保存（`text=''`），记录保留，**不提供整篇删除**。
- 上一篇/下一篇箭头与月历圆点只认有非空文字的天；删空的日记箭头跳过，但仍可在月历逐日点到并重写。

时间边界：
- 可补写过去任意一天；**禁止写未来**：命令层校验 `date ≤ 当前设置时区下的今天`，月历未来日置灰不可选。

时区：
- 日记以工作区设置时区 `settings.zone` 为归属基准，日记页不另设时区切换。
- "今天"与新建默认日期按 `settings.zone` 换算（不使用 UTC，避免凌晨差一天）。
- 月历按本地日期聚合圆点，历史日记不因改时区挪动日期位置；某日存在跨时区多篇时，优先载入当前设置时区的一篇，无则载入最新一篇并标注其归属时区，数据不隐身。

界面：
- 左侧导航新增"日记"标签；页面两栏：左侧紧凑月历（月份切换、今天高亮、有文字天标圆点、未来置灰），右侧日期标题 + 纯文本大输入框 + 保存状态条。
- 自动保存：停顿约 1.2s 防抖入库；状态显示"保存中／编辑中／已保存（含时间）／失败"；失败可点状态条重试，文字保留在本地不丢；Ctrl/Cmd+S 立即存；切换日期或离开页面前强制存一次。

本项不做：富文本与排版、图片与附件、"全部日记"长列表、日记与收件箱互转、记录回顾并排、第二领域、统计与连续打卡、多端同步、个人真实数据处理。

## 完成标准

1. 升级到 Data v4 后，可在"日记"标签完成选日、书写、自动保存、刷新后重读同一篇；未升级的旧工作区按现行规则只读并引导迁移。
2. 浏览、切月、打开空白日均不产生记录；只有有效文字才建档；删空后记录保留、箭头跳过、月历仍可点到。
3. 补写过去成功；未来日期在月历置灰且命令层拒绝写入。
4. 自动保存状态正确流转；制造保存失败时文字不丢、可重试成功；切换日期不丢未存文字。
5. 跨时区换算正确：设置时区决定"今天"；跨时区多篇不丢、可载入。
6. 桌面与 320px 窄屏路径可用；现有 v0.3/v0.4 功能与浏览器门禁不回归。
