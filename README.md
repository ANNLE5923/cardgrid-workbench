# CardGrid · 卡格工作台

一款本地优先的个人日程与任务工作台。数据保存在当前浏览器的 IndexedDB，不需要账号，也不会由应用主动上传到服务器。

## 开始使用

需要安装 Node.js 22 或更高版本。Windows 用户双击“启动卡格工作台.bat”；也可以在终端在本仓库根目录运行 npm ci、npm run dev。随后访问 http://127.0.0.1:4173。开发服务器只监听本机回环地址，局域网设备无法直接访问。关闭服务器窗口即可停止。

首次打开是空白工作台。在 Schedule 建立日型和安排星期，在配置工坊按需添加卡片定义；Today 会生成当天快照。例行规则当前由 Planner 数据层管理，页面提供当天完成与跳过操作。

## 数据与隐私

- 数据按浏览器来源和用户配置隔离；换浏览器、设备、端口或清除站点数据会看到不同工作区或失去本机数据。
- 定期从“数据与备份”下载完整备份，并把备份保存在安全位置。完整备份可能包含私人日程和记录，不要随源码公开。
- IndexedDB 不是加密保险箱；本机浏览器配置文件的访问者可能访问其中数据。
- 离线缓存只包含应用文件，不缓存工作区数据。

## 开发

在本目录运行 npm ci、npm run dev、npm run build、npm test。

领域契约与状态流位于 src/planner.ts；IndexedDB 与恢复点位于 src/store.ts；测试和无个人数据的 fixture 位于 tests/。

## GitHub 准备

仓库边界是本目录。提交前确认没有加入备份 JSON、真实工作区导出、个人截图或本机数据。当前不附开源许可证；若公开仓库，需先选择许可证，未附许可证时他人通常没有默认复制、修改或再分发权限。GitHub Pages 子路径构建支持已配置；部署仍需自行配置仓库 Pages 设置。

私下分发时发送源码压缩包即可，收件人需要 Node.js 22+。不要把自己的浏览器备份放进压缩包。

详细上传和分发检查见 [DISTRIBUTION.md](DISTRIBUTION.md)。
