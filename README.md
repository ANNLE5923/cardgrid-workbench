# CardGrid · 卡格工作台

本地优先的个人行动工作台：从空白开始，建立行动卡、选择并接受到手牌、安排进一天、确认实际发生并保留记录。

![当日双环与手牌，合成演示数据](docs/images/day-board-demo.png)

## 产品结构

- **工坊**：制作行动原卡、书目、分层卡池与每日/星期生成规则；支持表单、JSON、波浪矩阵与球面编辑。
- **抽卡**：按规则生成今日库存，球面两步翻牌或明确手选；槽位下拉首项“随机”立即固定具体词条，再接受完整行动。
- **日常**：独立手牌 `×n` 堆叠、双环排期、实际确认、只读事实与批注；到期副本归档，保留来源与历史。
- **日记**：一天一篇纯文本，停顿约 1.2 秒自动存，可补写过去、不写未来；月历逐日点选，上一篇/下一篇只跳有内容的天。

界面入口为 Today、Inbox、Schedule、行动定义、制卡工坊、抽卡手牌、日记、配置工坊和数据与备份。小屏与减少动态效果使用静止列表，也可手动切换；选择、翻开、接受的规则相同。

## 开始使用

需要 Node.js 22.18+（22.x）或 24+。

```sh
npm ci
npm run dev
```

打开 <http://127.0.0.1:4173/>。Windows 可使用 [启动脚本](scripts/启动卡格工作台.bat)。首次打开没有个人预置数据。

数据保存在当前浏览器的 IndexedDB，定期从“数据与备份”导出完整备份。更换浏览器来源可能看到不同工作区，升级或迁移前先保留独立备份。详见[使用说明](docs/使用/使用说明.md)。

## 当前状态

产品版本 v0.5.0：新增“日记”——一天一篇纯文本，停顿约 1.2 秒自动存（失败保留本地草稿、可点着重试，状态显示已保存/保存中/失败），跟随工作区设置时区，可补写过去、不写未来，月历逐日点选、上一篇/下一篇只跳有内容的天。数据升级到 Data v4（dataFormat action-v4）；Envelope 保持 schema v4，新工作区直接使用 Data v4，旧 Data v3 经“下载完整备份→预览→显式提交”升级，Data v2 精确恢复与日常操作保留。v0.4 的 Today 正式双环入口收敛、v0.3 的制卡工坊与每日库存闭环均已通过分离验收。不会自动迁移个人数据。

副本按来源日保留 D—D+6，D+7 起归档并撤销其未完成排期，事实与批注保留。离线漏日不自动补；可手动补保留期内有版本证据的日期。主动重复接受创建独立手牌，同一次保存重试只重放一次。当前验收和未测范围见[v0.5 版本记录](docs/归档/v0.5/README.md)，前版见 v0.4、v0.3 版本记录。
