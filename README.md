# CardGrid · 卡格工作台

本地优先的个人行动工作台：从空白开始，建立行动卡、选择并接受到手牌、安排进一天、确认实际发生并保留记录。

当前开发预览版本为 **v0.6.1-preview.1**，稳定发布基线为 v0.5.0。预览版包含已整合的 v0.6 通用卡牌框架，以及存储变更种类通知和异常广播校验。现有订阅者继续全量刷新；按种类跳过无关刷新的界面优化尚未接入。版本、验证与交付范围见[预览记录](docs/开发/2026-10-06-v0.6并行开发计划.md#26-开发预览2026-10-09)。

新格式提供通用清单、行动／决策牌堆、三槽合成、右下角统一手牌、时间线日记、维护日志、单向文本文件及月度 ZIP 只读历史。吃饭、阅读、锻炼使用同一流程；只有 Today 可打出。

这是开发预览版。真实系统目录授权／撤权／重新授权、实体触屏和完整发布验收仍待完成；预览源码上传不代表这些项目通过，也不包含个人数据升级。此前 `c8bb77e` 的 [CI 37571935868](https://github.com/ANNLE5923/cardgrid-workbench/actions/runs/37571935868) 已成功，本次预览提交的 CI 以对应 Actions 记录为准。

## 产品结构

代码入口与文件归属见[模块地图](docs/架构/README.md)。[编码与版本收尾原则](AGENTS.md)规定开发中的状态、接口和数据边界，以及“整理代码 → 整理文件 → 验证 → 提交上传”的固定顺序；代码风格由自动检查保持。

- **工坊**：创建和编辑行动卡、条目、牌堆与决策；牌堆可单独作清单，三槽合成消耗选中的本次素材并保留原库。
- **抽卡与决策**：行动球面或手选，问题给出具体答案，明确接受后加入统一手牌；每日库存继续保留来源与历史。
- **Today**：双环排期、答案参考、实际确认与只读事实；统一浮窗跨页可查看，仅 Today 能打出。
- **时间线日记**：表盘自动段直接投影，独立感想保留时间戳与修改时间；收回安排不删除感想，旧日记全文保留。
- **数据与文件**：月度导出核验后明确移出，多个 ZIP 只读查看；业务与日记共用 JSON 备份，维护日志独立保存，文本文件单向生成。

v0.6 入口为 Today、工坊、抽卡与决策、时间线日记、维护日志、备份与恢复。小屏与减少动态效果使用静止列表，也可手动切换；选择、翻开、接受的规则相同。旧格式继续使用原界面；Data5 升级预览说明尚未接入的完整 Inbox／定义／项目页面，原数据保留。

## 开始使用

需要 Node.js 22.18+（22.x）或 24+。

```sh
cd app
npm ci
npm run dev
```

打开 <http://127.0.0.1:4173/>。Windows 可使用 [启动脚本](app/scripts/启动卡格工作台.bat)。首次打开没有个人预置数据。

想让 AI 帮你准备个人行动、候选清单、决策和作息，可从 [AI 协作创建配置包](docs/使用/AI协作创建配置包.md)开始：分轮了解需求、对齐方案、生成并校验 JSON，再在应用中预览导入。指引内有可复制的开场提示词和完整示例。

数据保存在当前浏览器的 IndexedDB，定期从“数据与备份”导出完整备份。更换浏览器来源可能看到不同工作区，升级或迁移前先保留独立备份。详见[使用说明](docs/使用/使用说明.md)。

## 已发布 v0.5 基线

产品版本 v0.5.0：新增“日记”——一天一篇纯文本，停顿约 1.2 秒自动存（失败保留本地草稿、可点着重试，状态显示已保存/保存中/失败），跟随工作区设置时区，可补写过去、不写未来，月历逐日点选、上一篇/下一篇只跳有内容的天。数据升级到 Data v4（dataFormat action-v4）；Envelope 保持 schema v4，新工作区直接使用 Data v4，旧 Data v3 经“下载完整备份→预览→显式提交”升级，Data v2 精确恢复与日常操作保留。v0.4 的 Today 正式双环入口收敛、v0.3 的制卡工坊与每日库存闭环均已通过分离验收。不会自动迁移个人数据。

副本按来源日保留 D—D+6，D+7 起归档并撤销其未完成排期，事实与批注保留。离线漏日不自动补；可手动补保留期内有版本证据的日期。主动重复接受创建独立手牌，同一次保存重试只重放一次。当前验收和未测范围见[v0.5 版本记录](docs/归档/v0.5/README.md)，前版见 v0.4、v0.3 版本记录。
